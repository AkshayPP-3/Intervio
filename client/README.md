# Intervio client

The client is a Vite + React + TypeScript application organized by feature.

- `src/components` contains reusable UI and common layout components.
- `src/features` contains feature pages, components, and services.
- `src/layouts` contains application-level layouts.
- `src/routes`, `src/context`, `src/hooks`, `src/services`, `src/types`, and `src/utils` contain shared application infrastructure.
- `src/assets` and `public/images` are reserved for application assets.

Run the client from this directory:

```bash
npm run dev
```
